## 概述

EduFlow 畅学 内置了四个核心 AI 智能体，通过智能编排引擎（Agent Orchestrator）协同工作，为学习者提供全流程的智能化学习体验。智能体基于 LangChain 框架构建，支持主流大语言模型（GPT-4o、文心一言 4.0 等），并可根据实际需求灵活切换。

## 1. 学习路径规划智能体 (Learning Path Agent)

### 1.1 功能概述

学习路径规划智能体负责根据学习者的目标、当前水平、学习偏好和时间安排，自动生成个性化的学习路径。该智能体是学习者在 EduFlow 畅学平台上的首站，帮助学习者明确学习方向并规划高效的学习路线。

### 1.2 核心功能

| 功能 | 说明 |
|------|------|
| **能力评估** | 通过初始测评或历史学习数据，评估学习者在目标领域的当前水平 |
| **路径生成** | 基于知识点图谱和课程依赖关系，生成从入门到精通的学习路径 |
| **动态调整** | 根据学习进度和测评结果，实时优化和调整学习路径 |
| **时间规划** | 结合学习者的可用时间，合理分配学习节奏 |
| **多目标支持** | 支持同时管理多个学习目标，规划复合型学习路径 |

### 1.3 工作流程

```

    │
    ▼
┌─────────────────────────────────────┐
```

## 2. 智能问答智能体 (Q&A Agent)

### 2.1 功能概述

智能问答智能体是基于 RAG（检索增强生成）技术的知识问答系统，能够结合课程知识库和通用知识库，为学习者提供精准、上下文感知的问答服务。支持多轮对话，能够理解复杂问题并给出结构化的回答。

### 2.2 核心功能

| 功能 | 说明 |
|------|------|
| **知识检索** | 从课程知识库和通用知识库中检索相关片段 |
| **多轮对话** | 维护对话上下文，支持连续追问和深入讨论 |
| **来源追溯** | 回答中标注知识来源，方便学习者查阅原始内容 |
| **相关推荐** | 自动推荐与当前问题相关的后续问题 |
| **多模态支持** | 支持文本、代码、公式等多种内容形式的问答 |

### 2.3 工作流程

```
    │
    ▼
```

## 3. 作业批改智能体 (Assignment Agent)

### 3.1 功能概述

作业批改智能体能够自动批改主观题和编程题作业，提供详细的评分反馈和改进建议。该智能体结合了静态代码分析、逻辑正确性评估和自然语言理解技术，能够像人类教师一样给出有针对性的评价。

### 3.2 核心功能

| 功能 | 说明 |
|------|------|
| **自动评分** | 根据评分标准自动评分，支持自定义评分量规 |
| **代码分析** | 对编程作业进行静态分析，检查代码质量、性能和安全性 |
| **逐行反馈** | 对代码逐行点评，指出问题并提供改进建议 |
| **错题分析** | 识别错误知识点，关联到对应课程内容 |
| **抄袭检测** | 基于代码相似度检测，发现抄袭行为 |
| **批量批改** | 支持教师批量提交作业进行统一批改 |

```
    │
    ▼
```

## 4. 学习分析智能体 (Analytics Agent)

### 4.1 功能概述

学习分析智能体负责多维度采集和分析学习者的学习行为数据，生成可视化的学习报告，帮助学习者和教师了解学习效果、发现潜在问题并做出针对性的改进。

### 4.2 核心功能

| 功能 | 说明 |
|------|------|
| **学习行为分析** | 分析学习时长、学习频率、学习时段偏好等行为模式 |
| **知识掌握度建模** | 基于测评结果和学习行为，构建学习者知识掌握度画像 |
| **学习效果评估** | 对比学习前后的能力变化，评估学习投入产出比 |
| **异常行为检测** | 识别学习停滞、成绩骤降、刷课等异常行为 |
| **个性化推荐** | 基于分析结果推荐复习内容、学习策略调整建议 |
| **班级报告生成** | 为教师生成班级整体学习情况统计报告 |

## 5. 智能体协作场景

### 5.1 学习闭环

四个智能体协同工作，形成完整的学习闭环：

```
学习路径规划智能体         智能问答智能体
    │                        │
    │  ① 规划学习路径          │  ③ 学习过程中随时提问
    ▼                        ▼
┌─────────────────────────────────────┐
│           学习者学习过程             │
└─────────────────────────────────────┘
    │                        │
    │  ④ 提交作业             │  ⑤ 查看分析报告
    ▼                        ▼
作业批改智能体             学习分析智能体
    │                        │
    │  ⑥ 反馈薄弱知识点 ────→ 更新知识掌握度模型
    │  ⑦ 推荐复习内容 ────→ 学习路径规划智能体调整路径
    └────────────────────────────────────┘
```

### 5.2 典型协作流程

1. **路径规划阶段**：学习路径规划智能体根据学习者的目标和水平生成初始学习路径。
2. **学习阶段**：学习者按照路径学习，遇到问题时通过智能问答智能体获得解答。
3. **评估阶段**：学习者完成课程后参加测评或在线上交作业，作业批改智能体进行自动批改。
4. **分析阶段**：学习分析智能体汇总学习数据，评估学习效果，识别薄弱知识点。
5. **调整阶段**：学习路径规划智能体根据分析结果调整后续学习路径，形成持续优化循环。

## 6. 技术实现

### 6.1 技术栈

| 组件 | 技术选型 |
|------|----------|
| AI 框架 | LangChain |
| 大语言模型 | GPT-4o / 文心一言 4.0 |
| 向量数据库 | Milvus |
| 向量嵌入模型 | text-embedding-3-large |
| 代码分析 | Pyright / ESLint |
| 消息队列 | RabbitMQ |
| 任务调度 | Celery |

### 6.2 扩展性设计

- **模型无关性**：通过抽象模型接口，支持无缝切换不同的 LLM 提供商。
- **插件化工具**：每个智能体可以注册和使用多种工具，工具可独立开发和扩展。
- **水平扩展**：智能体服务为无状态设计，支持通过增加实例来提升并发处理能力。
- **缓存策略**：对常见问题和知识检索结果进行缓存，减少 LLM 调用次数，降低延迟和成本。
